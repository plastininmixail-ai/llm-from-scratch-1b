# 📚 Как подключить модель к источнику знаний

## 📋 Что уже есть

В боте работает **Knowledge Base (KB)** — поисковик по базе фактов:

```
📁 data/chat_merged.jsonl (866 записей)
  ├─ chat.jsonl
  ├─ chat_ru.jsonl
  ├─ chat_school_ru.jsonl
  ├─ chat_school_en.jsonl
  └─ reasoning.jsonl
```

3 уровня поиска:
- **Exact match** — точный вопрос
- **Substring match** — частичное совпадение
- **Word overlap** — похожие слова (≥50%)

## 🚀 3 способа подключить новый источник

### 1️⃣ Добавить в существующую KB (самый простой)

Создай файл в формате JSONL:

```json
{"prompt": "Сколько рук у человека?", "response": "Две руки."}
{"prompt": "Сколько планет?", "response": "8 планет."}
```

**Плюсы**: мгновенно, бесплатно, 0 затрат GPU
**Минусы**: только exact/substring совпадения

### 2️⃣ Расширить hardcoded (для известных фактов)

В `inference/bridge_bot.py` уже есть **67 паттернов**:

```python
HARDCODED_ANSWERS = {
    r"\b2\s*\+\s*2\b": "Четыре. Два плюс два равно 4.",
    r"сколько\s*планет": "В Солнечной системе 8 планет.",
    # ... 65 других
}
```

**Плюсы**: 0ms latency, точный ответ
**Минусы**: ручная работа

### 3️⃣ RAG через embeddings (умный поиск)

Вместо word overlap — использовать **sentence embeddings**:

```
Вопрос → embedding → cosine similarity → top-K facts → prompt
```

**Плюсы**: понимает синонимы, контекст
**Минусы**: нужны embeddings (5-50MB модель)

## 🤔 Какой источник подключить?

- **Wikipedia dump** (~20GB) — все факты мира
- **Справочник по физике/химии** — школьные вопросы
- **QA-датасет** — типа SQuAD, NaturalQuestions
- **Своя база знаний** — то что ты сам соберёшь

## 💡 Ответ на твой вопрос

> "Как подключить модель к источнику знаний"

**НЕ нужно всё грузить в модель!** Это **RAG pattern**:
- Модель остаётся маленькая (114M)
- Знания хранятся отдельно (в KB / файлах / БД)
- При запросе — поиск → контекст → генерация

Это **стандарт индустрии** — так работают ChatGPT, Claude, etc.
